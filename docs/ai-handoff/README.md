# بسته پرامپت‌های تحویل پروژه مانا کلینیک

تهیه‌شده در ۲۸ مهر ۱۴۰۵ / ۲۰ اکتبر ۲۰۲۶، بر اساس کد محلی، مستندات موجود و بررسی‌ها و انتشارهای همین گفتگو.

این فایل‌ها پرامپت آماده کپی‌کردن‌اند؛ skill، دستور نصب یا درخواست خودکار برای اجرای عملیات نیستند. هر پرامپت زمینه و محدودیت‌های مشترک را تکرار می‌کند تا به‌تنهایی هم قابل استفاده باشد.

روش استفاده:
۱. ابتدا متن 00-start-here.md را به دستیار جدید بده.
۲. فایل بخش موردنظر را هم به آن بده؛ برای کار میان چند بخش، چند فایل مرتبط را ضمیمه کن.
۳. درخواست تازه خودت را در انتها بنویس. اگر قرار است کد تغییر کند، دسترسی امن به سورس فعلی را فراهم کن؛ پرامپت جای سورس و دیتابیس نیست.
۴. فایل‌های دارای رمز، کلید، اطلاعات مالی، پرونده مراجع و خروجی خصوصی را همراه بسته به سرویس خارجی نفرست.
۵. بعد از هر تغییر مهم، بخش مربوط و CHANGELOG را به‌روز کن تا بسته قدیمی نشود.

حدود قطعیت:
- پیامک و مسیر جدید اپ: در همین گفتگو پیاده‌سازی و روی سرور منتشر و بررسی شدند.
- سایر بخش‌ها: نقشه‌ای از کد و مستندات موجودند؛ ممیزی کامل، تست کامل دستگاه یا تأیید زنده همه قابلیت‌ها انجام نشده است.
- پیشنهاد ادامه با کار باقی‌مانده قطعی فرق دارد. جز موارد صریحاً ثبت‌شده، باگ تأییدنشده یا تعهد اجرایی برای دستیار بعدی نساخته‌ایم.
- هیچ راز ورود یا کلید سرویس در این بسته عمداً درج نشده است؛ نام حساب مدیر فقط برای توضیح سیاست دسترسی آمده است.
