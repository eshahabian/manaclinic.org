# اپ موبایل مانا کلینیک

اپ همان سایت [manaclinic.org](https://manaclinic.org) است؛ مثل اپ ۷ رخ، پوستهٔ اندروید سایت را باز می‌کند و منو، نوبت، ورود و بقیهٔ صفحات همان صفحات سایت‌اند.

باز کردن در Android Studio: پوشه `android/` را Open کنید و Run بزنید.

تماس، واتساپ، نقشه و اینستاگرام بیرون از اپ باز می‌شوند. پرداخت داخل اپ می‌ماند. دوربین و میکروفون فقط برای تماس تصویری سایت درخواست می‌شود.
