# تماس داخلی مانا — متوقف‌شده تا اعلام کاربر

این پوشه خارج از `cpanel/` است و با دستور استقرار فعلی سایت منتقل نمی‌شود. هیچ قسمت این نسخه نباید فعلاً فعال یا در `public_html` کپی شود.

- `source/`: نسخهٔ کامل فایل‌های تغییرکرده و جدیدِ این کار، پیش از برگرداندن سایت.
- `baseline/`: نسخهٔ قبلی فایل‌های موجود، از commit ثبت‌شده در `manifest.json`.
- `changes.patch`: اختلاف فایل‌های موجود؛ فایل‌های جدید جداگانه در `source/` نگهداری شده‌اند.
- `tests/`: تست‌ها، نتیجهٔ تماس محلی دو مرورگر، تصویر آزمایش و ابزارهای موقت. وابستگی‌ها و runtime از Git مستثنی‌اند و محلی نگهداری می‌شوند.
- `manifest.json`: مسیرها، هش فایل‌ها و مبنای بازگردانی؛ `verification.json` نتیجهٔ بررسی نهایی را ثبت می‌کند.

فایل‌های خصوصی تنظیمات سایت و LiveKit در این آرشیو کپی یا ویرایش نشده‌اند. هیچ تغییری روی هاست ارسال نشده است.

برای ادامهٔ کار، ابتدا تغییرات بعدی مخزن با این نسخه تطبیق داده شوند؛ `source/` نباید کورکورانه روی نسخهٔ جدید سایت کپی شود. مسیر اصلی تست‌ها `output/mana-call-check/` بوده است و در زمان ادامه باید مسیرهای نسبی تست‌ها نیز تنظیم یا به محل اصلی برگردانده شوند.
